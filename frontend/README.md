# JARVIS Frontend

The JARVIS command deck is a React + Vite frontend foundation. It currently runs on mock data and provides a clean seam for a future Python/FastAPI backend in `src/services/api.js`.

## Run locally

```bash
npm install
npm run dev
```

The app includes responsive navigation, a live clock, mock telemetry, a command console, fake listening mode, music controls, and settings toggles.
